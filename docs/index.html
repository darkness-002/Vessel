Core Principles

Less in the way. More by design.

Built from the operating system upward to eliminate runtime redundancy, protect credentials, and isolate storage boundaries.

OS-native efficiency

Vessel bypasses bundled Chromium runtimes. By utilizing the host's existing web rendering engine through Tauri v2 and Rust, memory overhead is slashed by 35% with instant cold start times.

Explore the architecture

Physical storage isolation

Every container window operates in an isolated data directory partition. Cookies, IndexedDB, and localStorage remain quarantined within their sandbox with zero cross-origin leakage.

See isolation rules

VSSL vault security

When closed, containers can be encrypted at rest using AES-256-GCM. Cryptographic keys are protected by your native OS Credential Store or derived via Argon2id passphrases.
